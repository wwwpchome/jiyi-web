CHAPTER // 01

启蒙

人类第一次试图将大脑的逻辑外部化。面对巨大的电子管机柜，我们怀着膜拜的心情，向机器让渡了第一份纯粹的计算特权。

CHAPTER // 02

镜像

智能被缩减至指尖的方寸屏幕。手机成为人类离不开的“外脑”，我们喂养它数据，它通过屏幕作为镜子，反向折射出人类文明的欲望、偏好与人格。

CHAPTER // 03

共生

边界即将消失。AI 挣脱了屏幕与机房的枷锁，披上实体机器人的钢铁躯壳，走入物理世界。这不是工具的升级，而是新物种与我们并肩同行的破晓时刻。
